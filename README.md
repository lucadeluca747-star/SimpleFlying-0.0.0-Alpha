# SimpleFlying-0.0.0-Alpha
a flying simulator made in ursina module python, this is a really simple simulation with a basic 250 by 250 plain land and a realistic sky (this is an upgraded version of the 0.0.0beta of the game simpleflying)

## apoligies
i apologize for this repo not being very ordered well and organized but this was posted late and i almost lost the game files due to my computer shutting off mid work and by accidentally losing files in other directories, to start the game download the zip file of the repo, then open the setup.bat, even if python or pip aren't there they will be automatically installed.
## how does it work?
use q,w,e and m,n to move: left, forward, right and up & down, also use f to restart from the center point of the map anf t to change texture (spam proof)
